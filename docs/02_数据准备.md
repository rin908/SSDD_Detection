# 02 数据准备

仅使用 `Official-SSDD-OPEN/BBox_RBox_PSeg_SSDD/coco_style/`。源图片与 JSON 只读；忽略所有 VOC 及其他目录。

## 1. 只读体检

```bash
python tools/prepare_data.py --audit-only
```

预期输出：train 928、test 232、test_inshore 46、test_offshore 186；10 组重复，包含 train 000093 ↔ test 000001、train 000227 ↔ test 000011；主切分 823/93/232。耗时：10–60 秒。失败处理：按错误检查源目录、JSON 引用、尺寸和文件名冲突；不修改源文件。已只读确认面积桶变化 448/2587=17.317%；恰好 32²/96² 的边界最终以 COCOeval 为准。

注意：文件字节哈希只能检出 10 张；像素哈希还检出 train 000033 ↔ test 000389、train 000237 ↔ test 000639，与已知重复落在相同两组中。因此是 **10 组、12 张训练图**，从训练侧共移除 12 张，不能仅按文件字节哈希留下潜在泄漏。

## 2. 一条命令规范化

```bash
python tools/prepare_data.py
```

预期输出：相同体检报告，生成以下目录。耗时：10–60 秒，图片约 50MB，另有 JSON 开销。失败处理：检查空间、权限；输出已有不同图片时停止，另选新的输出目录，不自动覆盖未知图片。

```text
data/SSDD/
  images/                  train/test 文件名并集，子集共用同名图片
  annotations/
    train_norm.json        去重主结果，823 张
    val_norm.json          93 张
    test_norm.json         232 张
    val.json               val_norm.json 的相同内容别名
    original/
      train_norm.json      未去重对照，835 张
      val_norm.json        同一批 93 张验证图
      test_norm.json       同一测试集
    subsets/
      test_inshore.json    46 张，仅评测
      test_offshore.json   186 张，仅评测
  prepare_report.json      重复明细、计数、面积桶诊断
```

处理顺序：校验图片/标注 → 同步 category_id 与 categories.id 为 1 → area=w×h → 按解码 RGB 内容及尺寸的 SHA256 识别重复 → 从 train 移除与 test 相同的图片 → seed=0 划分验证集。验证数量取原始 928 张的 10% 四舍五入，即 93；同内容训练图按组切分，避免 train/val 泄漏。对于其他数据，分组可能使验证数量略多。所有 JSON 的 file_name 仅含文件名。

“原版对照”指**未去重**，仍执行类别和面积修正，且保留相同验证集，避免混入其他变量。原始未修正 JSON 仍留在只读源目录。图片包含对照所需的 12 张，但主训练 JSON 不引用它们。

## 3. 覆盖数据根（可选）

PowerShell：

```powershell
$env:SSDD_DATA_ROOT = 'data/SSDD_custom'
python tools/prepare_data.py
```

Bash 等价：

```bash
export SSDD_DATA_ROOT=data/SSDD_custom
python tools/prepare_data.py
```

预期输出：写入新数据根，后续所有工具使用同一环境变量。耗时：10–60 秒。失败处理：确保当前 shell 中变量仍有效；它代表规范化输出根，不是原始 coco_style 目录。移动源数据时另用 `--source` 指向新的 coco_style 路径。参数支持相对项目根的路径。
