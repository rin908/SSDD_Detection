# 04 常见报错

## mmcv wheel 装不上 / DLL 或算子导入失败

```powershell
python --version
python -m pip show torch mmcv mmengine mmdet
python -m pip debug --verbose
```

预期输出：Python 3.10、锁定版本、兼容标签包含 cp310-win_amd64。耗时：5–20 秒。失败处理：确认当前为 `mmdetection`，按环境文档官方 wheel 命令重试；索引 404 立即停下报告。没有对应 wheel 时停止，不安装 mmcv-lite，不编译，不修改 site-packages。DLL 错误先核对 CUDA wheel 组合及 NVIDIA 驱动，不用安装 Build Tools 解决本项目依赖。

## NumPy 2 / ABI 冲突

```powershell
python -m pip install "numpy<2"
python -m pip check
python tools/check_environment.py
```

预期输出：NumPy 1.x、无依赖冲突、CUDA NMS 通过。耗时：1–3 分钟。失败处理：只在新环境中操作，检查是否有其他包强制 NumPy 2；不要连带升级 torch/mmcv/mmdet。

## 8GB CUDA OOM

按顺序尝试，每条都会启动一个新实验，非本阶段执行命令。

1. batch=2 → 1：

```bash
python tools/train.py --work-dir work_dirs/ssdd_b1 --cfg-options train_dataloader.batch_size=1
```

预期输出：有效 lr=0.00125，显存占用降低。耗时：训练参考 40–70 分钟，batch=1 可能更慢。失败处理：仍 OOM 执行下一步。

2. 再降输入为短边 640、长边上限 800，同时修改训练/验证/测试：

```bash
python tools/train.py --work-dir work_dirs/ssdd_b1_small --cfg-options train_dataloader.batch_size=1 "train_dataloader.dataset.pipeline.2.scale=(800,640)" "val_dataloader.dataset.pipeline.1.scale=(800,640)" "test_dataloader.dataset.pipeline.1.scale=(800,640)"
```

预期输出：训练输入上限降低。耗时：通常更快，以实测为准。失败处理：仍 OOM 执行下一步。

3. 最后开启 AMP：

```bash
python tools/train.py --amp --work-dir work_dirs/ssdd_b1_small_amp --cfg-options train_dataloader.batch_size=1 "train_dataloader.dataset.pipeline.2.scale=(800,640)" "val_dataloader.dataset.pipeline.1.scale=(800,640)" "test_dataloader.dataset.pipeline.1.scale=(800,640)"
```

预期输出：AmpOptimWrapper、动态 loss scale。耗时：取决于 GPU。失败处理：关闭占用显存的其他进程后重试，保留报错日志，不自行修改锁定版本。降级实验评测和 FPS 要传相同 `--cfg-options` 与 `--work-dir`；FPS 仍 FP32，需在单图条件下能装入显存。

## Windows DataLoader 卡死 / 内存不足

```bash
python tools/train.py --cfg-options train_dataloader.num_workers=0 val_dataloader.num_workers=0 test_dataloader.num_workers=0
```

预期输出：单进程读图继续迭代。耗时：排查约 1 分钟，训练可能变慢。失败处理：从终端运行带 main 保护的项目入口，不要在 notebook 中直接创建 Runner；默认已设 spawn 与 persistent_workers=False。评测同样可追加 `--cfg-options test_dataloader.num_workers=0`。15.2GB 内存机器关闭其他大内存应用。

## pycocotools 安装失败

```powershell
python -m pip install pycocotools --only-binary=:all: --index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -c "from pycocotools.coco import COCO; from pycocotools.cocoeval import COCOeval; print('COCO OK')"
```

预期输出：安装 wheel、COCO OK。耗时：1–3 分钟。失败处理：检查镜像是否同步 cp310 Windows wheel，网络恢复后重试；无兼容 wheel 时停止报告，不在无编译工具的机器上尝试源码。不要替换为非标准包后忽略依赖冲突。

## PowerShell 拒绝脚本执行

```powershell
python tools/train.py
```

预期输出：与 train.ps1 相同的训练入口。耗时：启动约 10–30 秒，训练另计。失败处理：先确认 conda 环境和数据；无需修改系统执行策略。
