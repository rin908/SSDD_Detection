# 01 环境搭建

在项目根打开 Anaconda PowerShell Prompt。以下步骤由你手动执行；项目交付阶段没有安装包。仅操作新建的 `mmdetection` 环境，禁止改动已有 `pytorch`、`xiaotudui` 环境。驱动显示的 CUDA 12.7 是驱动兼容上限；本项目 torch wheel 自带 CUDA 11.8 运行时，不需要安装 CUDA Toolkit 或编译工具。

## 1. 新建环境

```powershell
conda create -n mmdetection python=3.10 -y
conda activate mmdetection
python --version
```

预期输出：Python 3.10.x，提示符为 `(mmdetection)`。耗时：1–5 分钟。失败处理：检查 conda 可用性；若环境已存在，只激活并核查版本，不删除或升级其他环境。也可用 `conda env create -f environment.yml` **替代创建命令**；该文件只建隔离环境，Python 包按后续顺序安装。

## 2. 限定当前环境的 pip 源，安装 NumPy

```powershell
python -m pip config --site set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install "numpy<2"
```

预期输出：配置写入当前环境、NumPy 1.x。耗时：1–3 分钟。失败处理：先确认已激活正确环境；不要使用全局 pip 配置。

## 3. 安装固定 CUDA wheel

```powershell
python -m pip install torch==2.1.0+cu118 torchvision==0.16.0+cu118 --index-url https://download.pytorch.org/whl/cu118
```

预期输出：Successfully installed torch-2.1.0+cu118 torchvision-0.16.0+cu118。耗时：5–20 分钟（软件包较大，取决于网络）。失败处理：检查官方索引连接后重试相同版本，不换 CPU 包，不升级版本。

## 4. 只安装官方 mmcv 二进制包

```powershell
python -m pip install mmcv==2.1.0 --no-index --find-links https://download.openmmlab.com/mmcv/dist/cu118/torch2.1/index.html --only-binary=:all: --no-deps
```

预期输出：选中 `mmcv-2.1.0-cp310-cp310-win_amd64.whl`，没有 Building wheel。耗时：1–5 分钟。失败处理：若索引 404，**立即停止并报告 URL 和错误**；严禁改用源码、mmcv-lite 或自行编译。`--no-index` 与 `--only-binary` 保证不会退回 PyPI 源码包。此步暂不装依赖，下一步统一解析。

## 5. 安装其余固定依赖

```powershell
python -m pip install -r requirements-lock.txt
python -m pip check
```

预期输出：mmengine 0.10.4、mmdet 3.3.0；No broken requirements found。耗时：2–10 分钟。失败处理：确认步骤 3、4 成功，pip 应显示 torch/mmcv already satisfied；若试图替换它们，停止，检查当前 Python 与环境。`requirements-lock.txt` 按请求固定核心版本，NumPy 保留 `<2`，pycocotools 及传递依赖不是全量哈希锁。

## 6. 验收版本、CUDA 算子与配置

```powershell
python -c "import torch,mmcv,mmdet;print(torch.__version__,torch.version.cuda,mmcv.__version__,mmdet.__version__)"
python tools/check_environment.py
```

预期首行**必须**为：

```text
2.1.0+cu118 11.8 2.1.0 3.3.0
```

后续两个配置显示 Config OK，最后显示 CUDA NMS / 环境检查通过。耗时：10–30 秒。失败处理：见 [常见报错](04_常见报错.md)，未通过前不要训练。本机交付时尚无此新环境，因此此输出是验收目标，非已完成实测。
