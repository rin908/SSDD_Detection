# 超参表

| 参数 | 主结果 | 说明 |
|---|---|---|
| 检测器 | Faster R-CNN R50-FPN | mmdet 3.3.0 官方基配置 |
| 类别 | ship，1 类 | COCO category id=1 |
| 骨干初始化 | ImageNet ResNet-50 | 首次训练可能下载约 100MB 权重 |
| 输入 | 短边 800、长边上限 1333 | 保持比例；预处理补齐到 32 倍数 |
| batch | 2 / 单卡 | RTX 4060 Laptop 8GB |
| 优化器 | SGD | momentum=0.9、weight_decay=0.0001 |
| 有效学习率 | 0.0025 | 基础 0.02 × batch 2 / base_batch_size 16 |
| 自动缩放 | enable=True，base_batch_size=16 | batch=1 时有效 0.00125 |
| warmup | 500 iteration，LinearLR | start_factor=0.001 |
| schedule | 12 epoch | 第 8、11 epoch 乘 0.1 |
| workers | 4 | persistent_workers=False，spawn |
| 随机性 | seed=0、deterministic=True | cudnn_benchmark=False |
| 增强 | 等比缩放、水平随机翻转 p=0.5 | 无颜色增强 |
| 验证 | 每 epoch | 最佳 checkpoint 按 val coco/bbox_mAP |
| 精度 | 默认 FP32 | 1024 变体训练 AMP |
| 可选变体 | 1024×1024 / batch=1 / AMP | 等比缩放后补零；FPS 始终 FP32 |
| 预计耗时 | 40–70 分钟 | 单卡参考，非性能承诺或实测 |

配置写基础 lr=0.02，是为保证自动缩放后实际 lr=0.0025；若同时写 0.0025 并开启缩放，会错误地再次除以 8。训练启动时打印有效学习率，warmup 初期日志中的 lr 会更低。
